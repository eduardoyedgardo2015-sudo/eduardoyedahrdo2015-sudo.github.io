NEXUS — Sitio web institucional (versión inicial)

ARCHIVOS
- index.html: estructura y contenido del sitio.
- styles.css: diseño adaptable a computadora, tablet y celular.
- script.js: menú móvil, enlaces de reservas y modal informativo.
- config.js: datos oficiales que faltan para conectar canales reales.
- assets/: logo y banner conceptual.

CÓMO VERLO
1. Descomprimí la carpeta nexus_web.
2. Abrí index.html con Chrome, Edge o Firefox.
3. Para publicarlo, subí todos los archivos y carpetas manteniendo la misma estructura a un hosting estático (por ejemplo, Netlify, GitHub Pages o el hosting de un dominio).

DATOS PARA COMPLETAR ANTES DE PUBLICAR
Abrí config.js y completá solo cuando estén confirmados:
- bookingUrl: enlace público de Calenda.
- whatsappNumber: número de WhatsApp en formato internacional, solo dígitos.
- instagramUrl: enlace del Instagram oficial.
- address: dirección pública confirmada.
- openingHours: horarios oficiales.

IMPORTANTE
- El contenido presenta a NEXUS como un proyecto en planificación, no como un establecimiento ya abierto.
- No se inventaron dirección, teléfono, horarios, precios ni fecha de apertura.
- La referencia a cuatro mesas de tenis de mesa recoge la decisión provisional conversada; confirmarla antes de presentar el proyecto como definitivo.
- El banner y el logo incluidos son imágenes conceptuales generadas para esta propuesta.
- El formulario de reservas no simula una reserva real: el botón se conectará a Calenda cuando se agregue su URL oficial.
