NEXUS — Sitio web institucional (versión conceptual)

ARCHIVOS
- index.html: estructura y contenido del sitio público.
- styles.css: diseño adaptable a computadora, tablet y celular.
- script.js: menú móvil, enlaces y modal informativo de reservas.
- config.js: configuración pública del sitio, aún pendiente de completar.
- js/firebase/: inicialización existente del cliente Firebase; no es un sistema operativo de reservas.
- assets/: logo y banner conceptual.

CÓMO VERLO
1. Abrí index.html con Chrome, Edge o Firefox.
2. Para publicarlo, subí los archivos y carpetas conservando su estructura a un hosting estático compatible, como GitHub Pages.

DATOS PARA COMPLETAR ANTES DE PUBLICAR
Completá la configuración pública solo cuando estén confirmados los datos oficiales y los destinos de enlaces del sitio. El enlace de reservas, cuando corresponda, deberá apuntar al futuro sistema propio de NEXUS, no a un motor externo de disponibilidad.

IMPORTANTE
- El contenido presenta NEXUS como un proyecto en etapa de desarrollo, no como un establecimiento ya abierto.
- No se inventan dirección, teléfono, horarios, precios ni fecha de apertura.
- El contenido del sitio es conceptual y no confirma por sí mismo instalaciones, capacidades ni configuraciones físicas.
- Las imágenes incluidas son conceptuales.
- El flujo actual no completa reservas reales. La inicialización del cliente Firebase no acredita autenticación funcional, operaciones de Firestore ni disponibilidad.
- Firebase es el backend decidido para el futuro sistema propio de reservas. No se debe presentar como implementado o configurado hasta verificarlo.
